## 二、环境说明（与玩家无关）

一键脚本 `tools/build_all.bat` / `tools/build_all.sh` 会依次构建 18 个版本，产物落在 `build/libs/`。  
这些脚本**只给开发者本地出包用**，玩家启动游戏时启动器会自动准备对应 Java，无需任何手动操作。  
本机工具链在 `.buildenv/`（JDK 21 + Gradle 8.14），`settings.gradle` 会按目标 MC 版本选择匹配的 Fabric Loom。

> 玩家运行时依赖：**Fabric Loader、Fabric API、Cloth Config API**（必需），**Mod Menu**（可选）。  
> Java：1.20.1–1.20.4 用 Java 17，1.20.5 及以上用 Java 21，由启动器自动处理。

## 三、M 站（Modrinth）发布步骤

1. 打开 <https://modrinth.com>，登录（右上角可切中文界面）。
2. 头像 → **创作者面板 / Creator Dashboard** → **创建项目 / Create a project**，类型选 **模组**。
3. 填写项目信息：
   - **名称**：`Custom Discs`
   - **摘要**：用本地音乐自定义我的世界唱片，游戏内设置音乐源
   - **说明**：复制本文第七节 FAQ
   - **分类 / 标签**：`Fabric`、`Client`、`Utility`、`Audio / Music`
   - **许可证**：`MIT`
   - **图标**：自行上传
4. 进入项目 → **创建版本 / Create version**。
5. **按 `上传清单.csv` 逐行操作，共 18 个版本**（每行一个 jar）：
   - **Version number**：填该行 MC 版本，如 `1.20.1`；**Version type** 选 `Release`
   - **Supported game versions**：**只勾这一个** MC 版本
   - **Loaders**：勾 `Fabric`
   - **Dependencies**：`Fabric API` 必选、`Cloth Config` 必选、`Mod Menu` 可选
   - 上传该行对应的 jar
   - 点 **创建 / Create**
6. 可选项：在设置里关联 CurseForge 项目、填写 Issues / Source 链接。

> M 站是「一个项目 = 多个版本」结构。上传时**一次只勾一个游戏版本**，  
> 否则会被平台判定为宽兼容版本（早期用 `>=1.20` 就出过这个问题）。

## 四、C 站（CurseForge）发布步骤

1. 打开 <https://www.curseforge.com>，注册并申请成为 **创作者 / Author**（首次需审核）。
2. **我的项目 / My Projects** → **创建项目 / Add Project**：游戏选 Minecraft、分类 Mod、加载器 Fabric。
3. 填写项目信息（名称、简介、说明、图标、许可证 MIT）。
4. 进入项目 → **上传文件 / Upload File**。
5. **按 `上传清单.csv` 逐行上传，共 18 个文件**：
   - 选择对应 jar
   - **Game Versions**：只勾对应的那一个 MC 版本
   - **Mod Loaders**：勾 `Fabric`
   - **Relationships**：Required 加 `Fabric API`、`Cloth Config`；Optional 加 `Mod Menu`
   - 发布通道选 `Release`
6. 可选项：在设置里关联 Modrinth 项目链接。

## 五、让启动器「看到」并自动安装的关键

| 关键字段 | 怎么填                                                    | 填错后果                     |
| ---- | ------------------------------------------------------ | ------------------------ |
| 游戏版本 | 每个 jar 只勾 `上传清单.csv` 里对应的那一个版本                         | 玩家选了该 MC 版本却搜不到，或装到不兼容的包 |
| 加载器  | 勾 `Fabric`                                             | Fabric 玩家搜不到             |
| 依赖   | Fabric API、Cloth Config 标 Required；Mod Menu 标 Optional | 启动器不会自动补依赖，玩家进游戏报错       |

- 读 Modrinth 源：Modrinth App、Prism Launcher、ATLauncher、PolyMC、GDLauncher、HMCL（部分）。
- 读 CurseForge 源：CurseForge 官方启动器、Prism Launcher、GDLauncher、ATLauncher、HMCL。

玩家搜索 **「Custom Discs」**，选对应 MC 版本即可一键安装，启动器会按依赖自动拉取 Fabric API 与 Cloth Config。

## 七、FAQ（可直接作为项目说明正文）

**Q：这个模组做什么？**  
A：允许玩家通过游戏内设置界面指定本地 `.ogg` 音乐文件作为「音乐源」，模组扫描后生成自定义唱片，  
支持创造标签页、命令 `/customdiscs give <id>` 与合成配方三种获取方式。

**Q：支持哪些版本？**  
A：Fabric 加载器，共 18 个版本：Minecraft 1.20.1–1.20.6 与 1.21–1.21.11。  
每个 jar 只对应一个游戏版本，请按自己游戏版本下载。

**Q：音乐文件要什么格式？**  
A：必须是 `.ogg`（Ogg Vorbis），MP3 / WAV 无法被游戏声音系统加载。  
可用 `ffmpeg -i in.mp3 -c:a libvorbis out.ogg` 转换。

**Q：怎么添加我自己的音乐？**  
A：把 `.ogg` 放进 `<游戏目录>/config/customdiscs/music/`，重启游戏即可。  
在 `Esc → Mods → Custom Discs → Configure` 里可改音乐源路径、重新扫描、开关合成配方。

**Q：为什么新增音乐没出现？**  
A：Minecraft 注册表在启动时锁定，新增 / 删除音乐文件后需重启游戏；仅替换某个 ogg 的内容可热更新。

**Q：需要装什么？**  
A：Fabric Loader、Fabric API、Cloth Config API 为必需，Mod Menu 可选（用于打开设置界面）。

**Q：版权声明**  
A：模组**不内置任何音乐**，所有音乐由玩家自行提供。请仅使用你拥有版权或已获授权的音乐，勿分享未授权内容。
